## Common Threat Vectors (Domain 2)

A **threat vector** is the method or pathway an attacker uses to gain access to a system, network, or organization. This lesson maps the full landscape of vectors so your defenses — and your exam answers — aren't blind to any major avenue.

---

### Message-based vectors

**Email** is the single most common initial-access vector. Attackers send **phishing** messages — fraudulent emails designed to deceive recipients — carrying either malicious links (leading to credential-harvesting pages or drive-by malware downloads) or malicious attachments that execute code when opened.

- **Smishing** — phishing via SMS text message; small screens make URL inspection hard, and texts feel urgent
- **Instant messaging / collaboration platforms** (Teams, Slack, Discord) — once inside, attackers can impersonate colleagues and share malicious files that feel far more trustworthy than external email

> Think of a phishing email like a fake parking ticket under your windshield — it looks official, creates urgency, and leads you to a site that steals your info.

---

### Image-based vectors

**Image-based attack vectors** exploit the complex code that renders image files, which can be manipulated to carry hidden payloads.

- **SVG** (Scalable Vector Graphics) — an image format that is actually an XML document; it can contain embedded JavaScript that a browser may execute when rendering the image, enabling **XSS** (cross-site scripting — injecting malicious scripts into web content viewed by other users)
- **Steganography** — the technique of hiding data or malicious code inside an image file invisibly, used to conceal payloads or exfiltrate data
- **Polyglot files** — a file that is simultaneously a valid image AND valid executable code, tricking format parsers that assume a file is only one type

> A polyglot file is like a business card that is also a lock-pick — it looks harmless to one inspector, but another reader sees a tool.

---

### File-based vectors

**File-based attack vectors** use any file format capable of carrying malicious content — not just executables.

- **VBA macros** — small programs embedded in Microsoft Office documents that automate tasks; attackers use social engineering ("enable macros for proper formatting") to get users to run them
- **PDFs** — can contain embedded JavaScript or exploit vulnerabilities in PDF reader software
- **ZIP/RAR archives** — hide a malicious file among hundreds of legitimate ones
- **LNK files** — Windows shortcut files that can be crafted to execute arbitrary commands when opened; used in sophisticated APT (**Advanced Persistent Threat** — a stealthy, long-term attacker, often nation-state) campaigns
- **Malicious browser extensions** — intercept traffic, harvest credentials, and exfiltrate data while appearing useful

---

### Voice-based vectors

**Voice call vectors** attack human targets over telephone systems.

- **Vishing** (voice phishing) — an attacker calls impersonating a bank, the IRS, or IT helpdesk, using urgency to extract credentials or remote access
- **Caller ID spoofing** via **VoIP** (Voice over IP — phone calls carried over the internet) makes calls appear to come from any number
- **SPIT** (Spam over IP) — automated VoIP systems dialing millions of numbers with recorded social engineering scripts
- **War dialing** — systematically dialing phone number ranges looking for modem connections or exploitable phone-connected systems

> Vishing is like a con artist in a convincing uniform at your door — the costume (spoofed caller ID) buys trust before the scam begins.

---

### Removable media vectors

**Removable media** can bypass even well-hardened network perimeters entirely — no internet connection required.

- **Baiting** — scattering USB drives in a parking lot hoping an employee plugs one in; the drive auto-executes malware
- **HID emulation** — devices like the **USB Rubber Ducky** (a tool that disguises itself as a keyboard) appear to the OS as a trusted keyboard, then type hundreds of pre-programmed malicious keystrokes per second, bypassing software controls
- **Data exfiltration** — insiders or intruders copy sensitive data to a thumb drive and walk out

> A USB Rubber Ducky is a wolf in sheep's clothing — the OS sees "keyboard," so it trusts every keystroke, including commands to install malware.

---

### Vulnerable and unsupported software

**Vulnerable software** vectors exist because software complexity guarantees undiscovered bugs, and patching lags.

- **Exploit kits** — packaged attacker tools that automatically test a target for known vulnerabilities in browsers, PDF readers, Java, etc.
- Web applications are high-value targets: compromising the server affects every user session at once

**Unsupported systems** — devices or OSes past **end-of-life** (EOL), meaning the vendor releases no more security patches — are permanently vulnerable.

- Examples: Windows XP (EOL April 2014), Windows 7 (EOL January 2020), still found in healthcare and industrial environments
- Mitigations when you can't upgrade: **network isolation**, **application allowlisting** (only approved programs can run), enhanced monitoring

---

### Unsecured network vectors

**Unsecured networks** expose traffic when encryption or authentication is weak or absent.

- **Open Wi-Fi** — no encryption; nearby attackers can passively sniff all traffic
- **WEP** (Wired Equivalent Privacy — an old, now-broken wireless encryption protocol) has cryptographic weaknesses allowing key recovery in minutes
- **Evil twin access points** — rogue Wi-Fi points mimicking a legitimate network's name to intercept connections
- **Bluetooth** — used for device reconnaissance and exploited via implementation flaws in Bluetooth stacks
- Best practices: enforce **WPA3** (current strongest Wi-Fi encryption standard), require **802.1X** (port-based network authentication that verifies identity before granting access)

---

### Open ports and default credentials

**Open service ports** expand attack surface — every listening port is a potential entry point if the service is vulnerable or misconfigured.

- **Shodan** — an internet search engine that indexes internet-connected devices and their exposed services; attackers use it to find vulnerable software versions; defenders should use it to audit their own external exposure

**Default credentials** are factory-set usernames and passwords (e.g., admin/admin) built into routers, cameras, IoT devices, and printers.

- Publicly documented on sites like routerpasswords.com
- Combining a Shodan search with a default credential list gives attackers administrative access to thousands of devices with minimal effort
- **All default credentials must be changed before deployment**

---

### Supply chain vectors

**Supply chain vectors** compromise a target by first attacking a trusted third party.

- **Hardware tampering** — malicious components or firmware added during manufacturing or shipping
- **Software backdoors** — compromising build systems (e.g., the **SolarWinds Orion** attack, 2020, where malware was inserted into a legitimate software update delivered to thousands of customers)
- **Managed service providers (MSPs)** — companies hired to manage client infrastructure; their broad access makes them high-value targets
- **Third-party contractors** — the 2013 Target breach began through HVAC contractors with network access, who were pivoted through to reach point-of-sale systems
- **Counterfeit hardware** — fake equipment (documented with fake Cisco switches) that appears legitimate but contains hidden vulnerabilities

---

### Social media vectors

**Social media** enables both reconnaissance and social engineering before a single malicious packet is sent.

- Attackers mine LinkedIn, Facebook, Instagram, and Twitter to identify employees, map org structure, and gather personal details that make spear-phishing (highly targeted phishing aimed at a specific individual) convincing
- Fake profiles build trust over time before making a malicious request

---

### Recap
- **Message-based vectors** (email, smishing, IM platforms) are the most common initial-access path
- **Removable media** (baiting, HID emulation) bypasses network perimeter controls entirely
- **Unsupported systems** past EOL have no vendor patch remedy — compensating controls are the only option
- **Default credentials + Shodan** is a low-effort, high-yield attacker combo; change all defaults before deployment
- **Supply chain attacks** (SolarWinds, Target/HVAC) compromise targets through trusted third parties, not direct attack

### Exam flags
- **Smishing vs. vishing vs. phishing** — know which communication channel each uses and why each is effective
- **HID emulation / USB Rubber Ducky** — why the OS trusts it and how it bypasses software controls
- **Supply chain attack scenarios** — especially SolarWinds (software build compromise) and Target (third-party contractor pivot)
