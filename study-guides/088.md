## Security Tools (Domain 4)

Security professionals use a large, specialized toolkit — different tools for detection, scanning, analysis, cracking, exploitation, and forensics. This lesson maps each tool to its purpose so you can answer "which tool does X?" questions on the exam.

---

### Network intrusion detection and prevention

**Snort** is an open-source **NIDS** (Network Intrusion Detection System) that captures network traffic and alerts when packets match a database of known attack signatures.

- Three modes: **sniffer** (display packets live), **packet logger** (write to disk), **NIDS** (match signatures → alert)
- Rules specify protocol, source/destination addresses and ports, and payload content patterns

*Think of Snort as a bouncer with a mugshot book — it stops anyone whose face matches a known threat.*

**Suricata** is a high-performance, multi-threaded alternative to Snort that uses the same rule format but adds native inline **IPS** (Intrusion Prevention System — actively blocks, not just alerts) capability and handles high-throughput networks better.

**Zeek** (formerly **Bro**) takes a fundamentally different approach from signature matching — instead of comparing traffic to known attack patterns, Zeek **extracts metadata and writes structured logs**: DNS queries, HTTP requests, TLS certificate info, and connection records.

- No full packet capture needed; logs are compact and queryable
- Invaluable for threat hunting and investigation
- Cannot alert on known signatures the way Snort can

*Zeek is like a security camera that saves a written logbook — "car X entered at 9:02, exited at 9:47" — instead of raw video.*

**OSSEC** is a **HIDS** (Host-based Intrusion Detection System) that analyzes OS logs, monitors file integrity, and detects rootkits on individual machines — not network traffic.

**Wazuh** is a fork of OSSEC that evolved into a full security platform: HIDS + log analysis + vulnerability detection + compliance checking, with a modern web UI. Viable free alternative to commercial **SIEM** (Security Information and Event Management — a platform that aggregates and correlates security logs) products for smaller organizations.

### Vulnerability scanners

**Tenable Nessus** is the most widely deployed vulnerability scanner, known for its large plugin database and support for authenticated scanning across Windows, Linux, network devices, and cloud. Supports **SCAP** — **Security Content Automation Protocol**, a NIST-maintained standard that lets different tools consistently describe and check vulnerabilities and configuration baselines — including **CIS Benchmarks** (configuration security standards from the Center for Internet Security) and **DISA STIGs** (Defense Information Systems Agency Security Technical Implementation Guides — hardening checklists for government systems).

**Qualys VMDR** (**Vulnerability Management Detection and Response**) is a cloud-based platform combining agent-based endpoint scanning, network scanning, and **CSPM** (Cloud Security Posture Management — checking cloud environment configurations for risk).

**Rapid7 InsightVM** integrates with Metasploit (see Exploitation Frameworks below) to show which vulnerabilities have working exploits available, adding real-world risk context.

**OpenVAS** (by Greenbone Networks) is the leading open-source vulnerability scanner — full authenticated network scanning at no license cost.

**Nmap** with the **NSE** (Nmap Scripting Engine) extends basic port scanning into vulnerability checking through community-developed scripts.

| Tool | Type | Notable strength |
|---|---|---|
| Nessus | Commercial | Largest plugin library; SCAP/STIG compliance |
| Qualys VMDR | Cloud SaaS | Agent + network + cloud posture in one |
| InsightVM | Commercial | Metasploit-informed exploit context |
| OpenVAS | Open-source | Free authenticated scanning |
| Nmap + NSE | Open-source | Lightweight; combines port scan + vuln check |

### Network analysis tools

**Wireshark** is the standard graphical packet capture and protocol analysis tool. It decodes hundreds of protocols, lets you follow TCP/UDP streams, extract files from HTTP sessions, and decrypt TLS using session keys. Saves captures in **pcap** format (packet capture file format — a standard binary format for storing raw network packets).

**Tcpdump** is the command-line equivalent — essential when no GUI is available (Linux servers, appliances). Example: `tcpdump -i eth0 -w capture.pcap` captures all traffic on the `eth0` interface and writes it to a file for later Wireshark analysis.

**Nmap** performs network discovery and security scanning:

| Flag | Function |
|---|---|
| *(none / default)* | TCP connect scan — enumerates open ports |
| `-sV` | Service version detection |
| `-O` | OS fingerprinting from network behavior |
| `-sU` | UDP scanning (finds services TCP scans miss) |

**Netcat** — called the "network Swiss army knife" — provides raw TCP/UDP connectivity for port scanning, file transfer, and creating reverse shell connections.

**NetFlow collectors** aggregate **NetFlow** (a protocol that records traffic flow metadata — source/dest IP, ports, bytes, duration — from capable network devices) to support traffic pattern analysis, capacity planning, and security monitoring.

### Password and credential tools

**Hashcat** is a GPU-accelerated password hash cracking tool that uses graphics card parallelism to test billions of candidates per second against captured hashes.

- **Dictionary attack** — tests every word in a wordlist
- **Rules-based attack** — applies transformation rules to wordlist entries (e.g., append "1!", capitalize first letter)
- **Brute force** — systematically tests all character combinations
- **Hybrid attack** — wordlist + brute force character appending
- Supports 300+ hash types: **NTLM** (Windows password hash format), **Kerberos** (Windows authentication protocol ticket hashes), MD5, SHA-1, SHA-256, bcrypt, and more

*Hashcat is like a locksmith with a robot that tries every key combination at machine speed.*

**John the Ripper** is a CPU-based cracker notable for **automatic hash type detection** and cross-platform support — slower than Hashcat but simpler to use.

**Hydra** performs **online password attacks** — it sends live authentication attempts over the network against running services (SSH, FTP, HTTP, SMB, LDAP, etc.). Unlike Hashcat/John (which crack offline hashes), Hydra tests credentials against a live target.

**Mimikatz** is a Windows post-exploitation tool that extracts credentials from the **LSASS** process (Local Security Authority Subsystem Service — the Windows process that handles authentication and stores credential material in memory).

- Extracts **NTLM hashes** and sometimes **plaintext passwords** from LSASS memory
- Enables **pass-the-hash** — authenticating with a captured hash without knowing the plaintext password
- Enables **pass-the-ticket** — reusing captured **Kerberos tickets** (authentication tokens issued by the Windows Kerberos system) for lateral movement
- Implements the **Golden Ticket attack** — forging Kerberos tickets using the **KRBTGT account hash** (the master key account used to sign all Kerberos tickets in Active Directory), granting persistent domain access
- Requires admin/SYSTEM-level access; used by both pen testers and real attackers

### Web application security tools

**Burp Suite** is the industry-standard web app pen testing platform:

- **Intercepting proxy** — sits between browser and server, captures and lets you modify HTTP/HTTPS requests
- **Scanner** — automatically tests for SQLi, XSS, and other common vulnerabilities
- **Repeater** — manually craft and resend modified requests
- **Intruder** — automates payload injection for fuzzing and brute force

**OWASP ZAP** (**Zed Attack Proxy**, from the Open Web Application Security Project — a nonprofit that publishes web security standards and tools) is a free Burp Suite alternative suited for development teams integrating security into **CI/CD pipelines** (automated software build and deployment workflows).

**Nikto** is a web server scanner checking for outdated software, default files/directories, missing security headers, and known server vulnerabilities. It is noisy and not stealthy — designed for authorized assessments.

**Sqlmap** automates detection and exploitation of **SQL injection** vulnerabilities — it finds injection points, identifies the database type, and extracts database contents automatically.

### Exploitation frameworks

**Metasploit Framework** is the most comprehensive open-source exploitation platform:

- **Exploit modules** — code targeting hundreds of known CVEs
- **Payload generation** — establishes remote control after exploitation
- **Auxiliary modules** — scanning and enumeration without exploiting
- **Post-exploitation modules** — privilege escalation, lateral movement

**Meterpreter** is Metasploit's advanced interactive shell payload: file system access, registry manipulation, credential extraction, pivoting through hosts, and screenshot capture — all over an encrypted channel.

**Cobalt Strike** is a commercial **adversary simulation** platform used by red teams. Its key differentiator: **malleable C2 profiles** — configurable command-and-control traffic that mimics legitimate application protocols to evade detection. Also heavily used by real threat actors; detecting **Cobalt Strike beacons** (persistent callback connections from a compromised host to the attacker's server) is a common incident response challenge.

### Digital forensics tools

**Autopsy** with **The Sleuth Kit** (a collection of open-source command-line forensic tools for analyzing disk images) provides a graphical open-source platform for disk image analysis: file system examination, deleted file recovery, timeline analysis, keyword searching, and hash-based file identification.

**FTK** (**Forensic Toolkit** by AccessData) is a commercial forensic platform commonly accepted in legal proceedings.

**Volatility** is the primary open-source **memory forensics** framework — it analyzes **memory dumps** (bit-for-bit copies of a system's RAM) to extract process lists, network connections, registry hives, and loaded modules from Windows, Linux, and macOS systems.

- Critical for **fileless malware** (malware that runs entirely in memory and writes nothing to disk) and rootkits that leave minimal disk artifacts
- Traditional disk forensics misses these threats entirely

*Volatility is like an MRI for a compromised machine — it sees what's happening in memory even when nothing is written to disk.*

**EnCase** is a comprehensive commercial forensic platform widely used by law enforcement and corporate investigations.

**Forensic imaging tools:**

| Tool | Type | Key feature |
|---|---|---|
| `dd` | Linux CLI | Bit-for-bit device copy |
| `dcfldd` | Linux CLI | `dd` + MD5/SHA-1 hash during imaging |
| FTK Imager | Windows GUI | Graphical acquisition + MD5/SHA-256 verification |

Hash verification during imaging confirms the copy is an exact, unaltered duplicate — essential for evidence integrity in legal contexts.

### Endpoint Detection and Response platforms

**EDR** (**Endpoint Detection and Response**) platforms continuously monitor endpoint behavior — process execution, network connections, file operations, registry changes — and enable rapid investigation and response. Traditional **antivirus** only matches files against known malware signatures at execution time and keeps no record of activity, so it cannot detect novel behavior or look back at what happened before an alert. EDR records a continuous behavioral timeline, enabling **threat hunting** (proactively searching historical endpoint data for signs of compromise).

| Microsoft Defender for Endpoint | Native Windows integration |
