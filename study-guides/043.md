## Other Malware Types (Domain 2)

This lesson covers the major malware categories beyond viruses and worms — ransomware, trojans, RATs, backdoors, rootkits, botnets, cryptominers, logic bombs, fileless malware, and wipers. These are high-frequency exam topics and reflect real-world attack patterns you'll encounter in security work.

---

### Ransomware: encryption as a weapon

**Ransomware** is malware that denies victims access to their own data or systems and demands payment for restoration.

**Crypto-ransomware** — the dominant, most severe variant — uses a two-layer encryption scheme:
- Generates a random **AES-256** (**Advanced Encryption Standard**, a symmetric cipher) key and encrypts all files with it
- Encrypts that AES key with the attacker's **RSA** (**Rivest–Shamir–Adleman**, an asymmetric cipher) public key
- The RSA private key lives only on attacker servers → victim cannot recover files without paying

**Locker ransomware** locks the screen or blocks OS login without encrypting files; less severe because data may be recoverable by booting from external media.

> Think of crypto-ransomware like a locksmith who changes your locks, then destroys every copy of the new key except the one he keeps — you cannot get in without calling him back.

---

### Ransomware extortion models

| Model | What it adds |
|---|---|
| **Single extortion** | File encryption only |
| **Double extortion** | Encrypts files + steals data first; threatens to publish it publicly |
| **Triple extortion** | Adds a **DDoS** (**Distributed Denial-of-Service**) attack against the victim during negotiations |

**Ransomware as a Service (RaaS)** — criminal developers build and lease ransomware platforms to **affiliates** who run attacks and split ransom revenue. Notable RaaS groups: **REvil, Conti, LockBit, BlackCat, Hive**.

---

### Landmark ransomware incidents

| Incident | Year | Key detail |
|---|---|---|
| **CryptoLocker** | 2013 | Established the modern crypto-ransomware template; Bitcoin via Tor |
| **WannaCry** | 2017 | Used NSA's **EternalBlue** exploit; disrupted ~80 UK NHS hospitals |
| **NotPetya** | 2017 | Looked like ransomware but was a **wiper** — decryption was never possible |
| **Colonial Pipeline** | 2021 | DarkSide RaaS; shut down US East Coast fuel supply for days |
| **Kaseya VSA** | 2021 | REvil; hit ~1,500 businesses via their managed service providers |

### Trojans and remote access trojans

A **trojan horse** is malware disguised as or bundled with legitimate software to trick users into running it. Unlike a virus, a trojan **does not self-replicate** — it depends entirely on social engineering for installation. Once run, the payload operates independently.

A **RAT (Remote Access Trojan)** is a trojan that gives an attacker full remote control of an infected system. Capabilities include:
- Screenshot, webcam, and microphone capture
- Keylogging and file exfiltration
- Executing arbitrary commands and installing additional malware
- Communicating silently over encrypted **HTTPS** or custom protocols with no visible UI

Known RAT families: **DarkComet, njRAT, AsyncRAT, Cobalt Strike Beacon** (a commercial red-team tool heavily abused by attackers).

> A RAT is like a hidden remote desktop session the attacker opened without asking — they can see your screen, hear your mic, and copy your files while you work normally.

---

### Backdoors

A **backdoor** is a covert, persistent access channel on a compromised system that bypasses normal authentication. Key traits:
- Survives reboots; resists removal even when other malware is cleaned
- Can be installed by other malware, a hands-on attacker, or a malicious insider embedded in legitimate software
- Communicates via encrypted protocols, **port-knocking** (sending a specific sequence of connection attempts to unlock a hidden service), or legitimate cloud services to evade detection

### Rootkits

A **rootkit** is malware whose primary goal is **concealment** — hiding itself, other malware, and attacker activity from the OS and security tools.

| Type | Where it operates | Power / Persistence |
|---|---|---|
| **Kernel rootkit** | Modifies the OS kernel itself | Highest — hides from all user-space tools including AV |
| **User-mode rootkit** | Hooks Windows API functions | Lower power, easier to build |
| **Firmware rootkit / bootkit** | Lives in UEFI firmware or the **MBR/VBR** (Master/Volume Boot Record) | Survives full OS reinstall; may require firmware reflash |

**Key kernel techniques:**
- **DKOM (Direct Kernel Object Manipulation)** — edits the kernel's internal linked list of running processes so the rootkit's process simply never appears
- **SSDT hooking** — intercepts **System Service Descriptor Table** calls (the OS table that maps system calls to kernel functions) to filter rootkit entries from results returned to any program asking about processes or files

**Detection and defense:**
- Scanning from within the infected OS is unreliable — the rootkit controls what the OS reports
- Must boot from **external trusted media** and scan from outside
- **Secure Boot** (a UEFI feature) verifies cryptographic signatures of the bootloader and OS kernel before running them, blocking unsigned bootkits
- **TPM (Trusted Platform Module)** — a dedicated security chip that records a measurement of system state at boot; comparing this to a known-good baseline can reveal tampering

> A kernel rootkit is like a corrupt police dispatcher who removes certain license plates from the database — every officer who queries the system gets a filtered list and never sees the car you're looking for.

### Botnets

A **botnet** is a network of compromised systems (**bots** or **zombies**) controlled by an attacker called a **bot herder** through **C2 (command-and-control)** infrastructure. Uses:
- Large-scale DDoS attacks
- Spam and phishing email campaigns
- **Credential stuffing** — automatically testing stolen username/password pairs against many services at once
- Click fraud and cryptocurrency mining

Notable botnets: **Mirai** (infected IoT devices using default credentials); **Emotet** (operated as a pay-per-install malware delivery service).

---

### Cryptominers (cryptojackers)

**Cryptominer** malware hijacks victim CPU/GPU resources to mine cryptocurrency without consent. Key details:
- **Monero** is the preferred target currency — CPU-friendly algorithm, privacy features block blockchain tracing
- Delivered via browser-based JavaScript on compromised sites, or installed background malware
- Effects: degraded performance, higher electricity bills, potential hardware damage from sustained load

---

### Logic bombs

A **logic bomb** is malicious code embedded in an otherwise legitimate system that stays dormant until a trigger fires, then executes a destructive payload.

| Trigger type | Example |
|---|---|
| **Time-based** | Delete all backups at midnight on a specific date |
| **Event-based** | Wipe files when a specific user logs in |
| **Absence-based** | Activate if the planted developer's account is removed (i.e., they were fired) |

- Most commonly planted by **malicious insiders** — disgruntled employees or departing contractors
- No AV signature can detect custom-written logic bombs proactively
- Detection requires: **integrity monitoring** of code and critical files, code review for unexpected conditional logic, and user behavior monitoring

> A logic bomb is like a departing employee leaving a timed safe in the server room — everything looks normal until the clock hits zero.

**Real example:** 2013 South Korea banking attack — a trojan delivered via email contained a logic bomb set to trigger at exactly 2:00 p.m. local time, simultaneously wiping systems at multiple banks and broadcasters.

---

### Recap
- **Crypto-ransomware** uses AES + RSA hybrid encryption; the private key never leaves attacker servers, making recovery without payment mathematically infeasible
- **Double/triple extortion** add data theft and DDoS pressure on top of encryption; **RaaS** is the criminal business model driving the explosion of incidents
- **Rootkits** hide malware at the kernel, user, or firmware level; detection requires booting from external trusted media; **Secure Boot** and **TPM** are key defenses
- **RATs** provide full silent remote control over infected systems via encrypted C2 channels
- **Logic bombs** are insider-planted, trigger-based payloads that no AV signature can catch — code review and integrity monitoring are the primary defenses

### Exam flags
- **Ransomware encryption mechanics** — know the AES + RSA hybrid model and why recovery without the private key is impossible
- **Rootkit types and detection** — kernel vs. user-mode vs. firmware/bootkit, why on-system scanning fails, and the roles of Secure Boot and TPM
- **Logic bomb triggers** — time-based, event-based, and absence-based; insider threat context
