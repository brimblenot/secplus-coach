## Spyware and Bloatware

This lesson covers the full range of covert monitoring software — from credential-stealing keyloggers to pre-installed manufacturer bloatware — and explains how each type installs, harms, and gets removed. Both categories appear on the Security+ exam.

---

### What spyware is and how it arrives

**Spyware** is software that covertly monitors user activity and collects information without meaningful informed consent. The defining trait is stealth: the user either doesn't know it's running or agreed to it under conditions that buried the true scope.

**Common installation vectors:**
- Peer-to-peer file-sharing networks
- Free software bundles (the spyware is the hidden "payment")
- **Fake security software** — presents itself as a protection tool while secretly installing the threat
- Malicious links in email

> Think of fake security software like a "security guard" you hired who is actually robbing you while on the job.

---

### Keyloggers: the most dangerous spyware subtype

A **keylogger** is software or hardware that records every keystroke a user types, capturing credentials before they ever reach an application — bypassing encryption that only protects data already in transit or storage.

**Hardware keylogger** — a small physical device inserted between a keyboard and computer (or embedded inside a keyboard), recording keystrokes to internal flash memory or transmitting them wirelessly.
- Completely invisible to software security tools — operates below the OS
- Found on hotel business center PCs, library terminals, ATM keyboards

**Software keylogger** — hooks into the OS keyboard input API — on Windows, via **SetWindowsHookEx** (a Windows API call that intercepts all keystrokes system-wide) or **GetAsyncKeyState** (an API call that polls for individual key states) — and runs as a hidden background process.
- Captured keystrokes are saved locally, then sent to attacker-controlled servers

**Mitigation:** **Password managers** autofill credentials without keyboard typing, so a keylogger captures nothing useful for autofilled fields.

| Property | Hardware Keylogger | Software Keylogger |
|---|---|---|
| Detection by antivirus | Impossible — below the OS | Possible — runs as a process |
| Physical access needed | Yes, to install | No |
| Defense | Port locks, physical inspection | Anti-malware, process audits |

> A hardware keylogger is like a wiretap spliced into the phone cord — the phone company (the OS) has no idea it's there.

### Other spyware types

**Screen capture spyware** periodically takes screenshots or records video, especially when banking or payment sites are detected — capturing data displayed on screen but never typed.

**Browser spyware** intercepts web activity: captures form submissions (including password fields) before they reach the server, redirects search results, injects ads, tracks browsing history, and targets stored passwords in the browser's built-in password manager.

**Credential harvesting spyware** specifically targets high-value apps — banking, email, cryptocurrency wallets — combining keylogging, screen capture, and **memory scraping** (reading credentials directly out of RAM) to steal authentication material.

**Stalkerware** is commercial spyware marketed for monitoring intimate partners or children without their knowledge. It hides from the app list, transmits location, messages, calls, and media to a remote server, and can survive factory reset.

---

### Adware, PUPs, and browser hijacking

**Adware** is software that displays unwanted ads, usually bundled with free software. The user technically consents via a lengthy terms-of-service, but disclosure is buried in legal language. Adware frequently arrives bundled with spyware — adware generates revenue while spyware sells the harvested data.

The security industry calls this category a **PUP/PUA** — **Potentially Unwanted Program / Potentially Unwanted Application** — software not overtly malicious but whose behavior a fully-informed user wouldn't consent to.

**Browser hijacking** is a specific adware behavior: the browser's homepage, default search engine, and new-tab page are changed to attacker-controlled alternatives. Hijackers may also install browser extensions that re-apply the changes even after manual restoration.

> Adware is like a "free" coupon book that, buried in the fine print, also sells your grocery receipts to marketers.

---

### Tracking technologies

| Technology | How it works |
|---|---|
| **Persistent cookie** — a small file storing a unique ID in the browser | Recognizes you across visits to the same site |
| **Supercookie / evercookie** — uses multiple browser storage locations (cookies, local storage, **IndexedDB** — a browser database for structured data, cached content) | Reconstructs your tracking ID even after cookies are deleted |
| **Browser fingerprinting** — collects browser version, fonts, screen resolution, timezone, language, plugins | Identifies you without any cookie, from the unique combination |
| **Tracking pixel** — a tiny transparent image loaded from the sender's server when an email is opened | Confirms the email address is active and records when/where it was opened |

### Bloatware and the Superfish incident

**Bloatware** (also called **crapware**) is manufacturer-pre-installed software on new devices. Hardware makers accept payment from software vendors to bundle their apps, which consume storage, run at startup, and can introduce security vulnerabilities on a brand-new device.

**The Superfish incident (Lenovo, 2015)** is the textbook case of bloatware causing genuine cryptographic harm:
- Lenovo pre-installed **Superfish** — advertising software that installed its own **root CA** (**root Certificate Authority** — a trusted entity whose certificate tells the OS to trust all certificates it signs) into Windows
- Superfish used this to perform **SSL man-in-the-middle** interception — decrypting HTTPS traffic to inject ads
- The same private key was used on every affected laptop; once extracted and published, any attacker could forge trusted certificates for any site on any affected device

> Superfish is like a locksmith who copied the master key to every house in a neighborhood and handed copies out to strangers.

**Removing bloatware:**
- Standard uninstall (works for some)
- Vendor-provided uninstaller (required for others)
- Third-party tools or clean OS reinstall (only option for the worst cases)

---

### Defenses

- **Antivirus/anti-malware** (e.g., **Malwarebytes** — a dedicated tool specializing in adware and spyware that general antivirus often misses) — scans processes and modules
- Audit installed apps, browser extensions, and mobile app permissions (microphone, camera, location, contacts)
- **Network traffic monitoring** — detects spyware "calling home" to collection servers
- **AMSI** — **Anti-Malware Scan Interface**, a Windows mechanism that lets security products scan scripts before they execute, blocking script-based spyware delivery
- **Hardware port locks** — physically block USB ports to prevent hardware keylogger installation
- Physical inspection of shared keyboards and ATM card readers

---

### Recap

- Spyware defines itself by **stealth** — covert monitoring without meaningful consent
- Hardware keyloggers are **invisible to software tools**; software keyloggers can be detected by antivirus
- Adware and spyware **arrive bundled** — adware earns revenue, spyware sells data
- **Stalkerware** is spyware targeting intimate partners/children, often surviving factory reset
- **Superfish** turned bloatware into a cryptographic attack by installing a shared root CA

### Exam flags

- **Hardware vs. software keylogger** — know that hardware keyloggers operate below the OS and are undetectable by antivirus, while software keyloggers run as processes and can be scanned
- **Superfish** — know it as the example of bloatware creating real cryptographic risk via a rogue root CA and SSL interception
- **PUP/PUA** — know the term and that adware/spyware commonly arrive together as a bundle
