## Endpoint Security

Endpoint security is the practice of placing security controls directly on individual devices — laptops, workstations, servers, phones — so they stay protected regardless of what network they're on. This matters because perimeter firewalls protect the network edge, but do nothing for a laptop compromised at an airport.

---

### Antivirus detection methods

**Antivirus/anti-malware software** scans files and processes for malicious code. There are three detection approaches, each catching what the others miss:

- **Signature-based detection** — the engine compares files against a database of known malware patterns. Fast and accurate for known threats, but completely blind to brand-new malware and **polymorphic/metamorphic malware** — malware that intentionally mutates its own code to avoid matching any stored signature.
- **Heuristic detection** — analyzes code structure and obfuscation patterns without needing an exact signature match, catching variants of known malware families. Trade-off: more **false positives** (legitimate programs flagged as suspicious).
- **Behavioral detection** — watches what a running process *does* at runtime: privilege escalation, injecting code into other processes, rapidly encrypting files, touching credential storage. Catches entirely new malware families because it doesn't care what the code looks like.

> Think of it like catching a thief: signature detection checks a mugshot database; heuristic detection checks whether someone is wearing a ski mask and gloves; behavioral detection watches someone actually pick a lock.

### EDR vs. XDR

**EDR (Endpoint Detection and Response)** — an agent installed on each endpoint that continuously records *everything*: every process, network connection, file write, registry change, and user action, streaming that telemetry to a cloud analysis platform.

Key EDR capabilities:
- **Real-time detection** via behavioral analytics and ML models
- **Forensic history** — investigators can reconstruct exactly what happened after a breach (traditional antivirus keeps no activity record, so it cannot do this)
- **Threat hunting** — analysts query historical telemetry fleet-wide (e.g., "which endpoints called this IP last Tuesday?")
- **Automated response** — quarantine a host, kill a process, or roll back ransomware file encryption remotely
- **Threat intel integration** — malicious hashes, IPs, and domains auto-blocked across all endpoints

| Vendor | Notable strength |
|---|---|
| CrowdStrike Falcon | Market leader, top detection rates |
| Microsoft Defender for Endpoint | Deep Windows/Microsoft ecosystem integration |
| SentinelOne | Autonomous AI-based response |
| Carbon Black (VMware) | Enterprise EDR |
| Cortex XDR (Palo Alto) | Cross-domain correlation built in |

**XDR (Extended Detection and Response)** — extends EDR by ingesting telemetry from *multiple domains simultaneously*: endpoints, network sensors, cloud workloads, and email security. It correlates signals across all four so that a multi-stage attack (phishing email → malicious link → C2 beacon → lateral movement) appears as one unified incident instead of four unrelated alerts.

> EDR is like a security camera inside one store. XDR is like the city-wide camera network that stitches footage together to follow the same suspect across every block.

### Host-based intrusion detection and prevention

**HIDS (Host-based Intrusion Detection System)** and **HIPS (Host-based Intrusion Prevention System)** monitor and protect at the individual system level. **OSSEC** and its modernized fork **Wazuh** are the leading open-source platforms. They provide:
- **File integrity monitoring** — detects changes to critical system files
- **Log analysis** — flags suspicious patterns in local logs
- **Rootkit detection** — looks for hidden processes or files
- **Active response** — automatically blocks IPs or takes protective action
- Agents forward data to a central manager for fleet-wide correlation

---

### Host-based firewalls

**Windows Defender Firewall with Advanced Security** filters inbound and outbound connections by port, protocol, remote address, and application. It uses three **profiles** — *domain*, *private*, and *public* — applying stricter rules automatically when a laptop joins an untrusted public network. Managed via **Group Policy** — the Windows enterprise mechanism for pushing settings to all domain-joined machines — in organizational environments.

Linux equivalents: **iptables** (traditional), **nftables** (modernized replacement), **firewalld** (user-friendly front-end).

---

### Data loss prevention on endpoints

**Endpoint DLP (Data Loss Prevention)** agents watch file operations — USB writes, email attachments, cloud uploads, print jobs — and block or alert when sensitive data patterns (credit card numbers, SSNs, classified keywords) are detected. Unlike **network DLP**, which only catches data leaving over the network, endpoint DLP also blocks local exfiltration paths like USB drives.

---

### Application control

**WDAC (Windows Defender Application Control)** — enforces code integrity policies at the **kernel level**, preventing unauthorized code from loading entirely. Cannot be bypassed from user mode, making it the highest-security option.

**AppLocker** — a **Group Policy**-based restriction tool that runs in **user mode**, allowing rules based on file path, cryptographic hash, or publisher signature. Easier to deploy; appropriate for most enterprises.

| Feature | WDAC | AppLocker |
|---|---|---|
| Enforcement layer | Kernel | User mode |
| Bypassable from user mode? | No | Yes |
| Deployment complexity | Higher | Lower |
| Best for | Highest-security environments | Standard enterprise |

### Disk encryption and patch management

**BitLocker** — Windows full-disk encryption backed by the **TPM (Trusted Platform Module)**, a dedicated security chip on the motherboard that stores encryption keys, enforcing **pre-boot authentication** so that removing the drive and reading it on another machine yields only ciphertext. Recovery keys stored in **Active Directory** or **Azure AD**. Mandatory on all laptops because physical theft is routine.

**Patch management** closes known vulnerabilities in the OS and applications. **WSUS (Windows Server Update Services)** handles Windows updates centrally. Third-party tools (Ivanti, ManageEngine Patch Manager Plus, PDQ Deploy) patch non-Microsoft software. Mature process: test in non-production → deploy in rings/waves → track compliance.

---

### Mobile and posture management

**MDM (Mobile Device Management)** platforms (Microsoft Intune, Jamf, VMware AirWatch) push and enforce security policies on phones and tablets: screen lock, disk encryption, OS update requirements, app-source restrictions, and **remote wipe** if a device is lost.

**Posture assessment** — a **NAC (Network Access Control)** solution checks a device's security state *before* granting network access: Is AV current? Are patches applied? Is encryption on? Non-compliant devices are dropped into a **quarantine network** — a restricted network segment with no production access — until remediated.

---

### Recap

- Behavioral detection catches new/unknown malware by watching *actions at runtime*; signature detection only matches *known* patterns.
- EDR continuously records all endpoint activity, enabling forensic investigation and threat hunting — capabilities impossible with traditional AV.
- XDR correlates signals across endpoints, network, cloud, and email into one incident view.
- WDAC enforces at kernel level (cannot be bypassed from user mode); AppLocker enforces at user mode (easier but bypassable).
- Posture assessment via NAC quarantines non-compliant devices before they touch the production network.

### Exam flags

- **Detection method differences** — know exactly what signature, heuristic, and behavioral detection each catch and miss, including false positive risk.
- **EDR vs. traditional AV** — EDR records continuous telemetry enabling threat hunting and forensics; AV cannot look back at historical activity.
- **WDAC vs. AppLocker** — kernel-level vs. user-mode enforcement, and which is appropriate for highest-security scenarios.
