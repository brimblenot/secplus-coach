Viruses and worms are two of the oldest and most foundational malware categories, and understanding the technical distinction between them is essential for the Security+ exam. The key difference is propagation: a virus requires a host file and some form of user action to spread, while a worm self-replicates autonomously across networks without any user involvement. Both have caused catastrophic damage throughout computing history, and several landmark incidents involving these categories have shaped how the security industry thinks about malware, patch management, and network defense.

A computer virus is malware that attaches to or embeds within a host file — an executable, document, script, or system area — and requires that host file to be executed or accessed by a user for the virus to activate. The virus cannot propagate independently; it depends on the host program running in order to copy itself to additional files or systems. Once active, the virus spreads as infected files are moved, copied, emailed, or accessed across the network. Some viruses cause immediately visible damage — crashing systems, deleting files, displaying messages — while others operate silently in the background for months or years, collecting information or waiting for a trigger condition.

File-infecting viruses are the classical category, appending malicious code to or overwriting executable files with extensions such as .exe, .dll, and .com. As infected executables are run, the virus gains control and copies itself to additional executables accessible from the infected system. Macro viruses embed in document files that support macro execution, particularly Microsoft Office documents using the Visual Basic for Applications macro language. Macro viruses became enormously prevalent in the late 1990s because email clients automatically opened attachments and Office macros ran without user confirmation by default. The Melissa virus spread via infected Word documents emailed to the first fifty contacts in the victim's Outlook address book, causing email server overload across the internet within days of its release. The ILOVEYOU virus, also called LoveLetter, spread via VBScript attachments in email messages and overwrote music, image, and other files with copies of itself, causing approximately ten billion dollars in damage.

Boot sector viruses infect the Master Boot Record or Volume Boot Record of storage media, executing before the operating system loads at every system start. Because they run before the operating system and therefore before antivirus software initializes, boot sector viruses can be extremely difficult to detect and remove from the infected system. They require specialized bootable scanning tools or removal from a separate clean system. The Petya ransomware used boot sector infection to lock entire systems by overwriting the MBR, requiring the boot sector to be repaired as part of recovery. Multipartite viruses combine both strategies, infecting both executable files and boot sectors simultaneously, which complicates removal because restoring only one infection site allows the other to reinfect it.

Polymorphic viruses use encryption to obscure their code, decrypting the payload at runtime using a decryption stub. On each new infection the virus re-encrypts itself using a different key, producing a completely different byte sequence in the storage-resident file. Because traditional signature-based antivirus looks for fixed byte patterns, a different signature on each infection defeats signature matching. Detection of polymorphic viruses requires heuristic analysis of behavior rather than byte pattern matching, or analysis of the decryption stub which, while variable, follows detectable structural patterns. Metamorphic viruses eliminate even the decryption stub by rewriting their entire code using semantic-preserving transformations on each infection — reordering independent instructions, substituting equivalent instruction sequences, inserting dead code. The resulting binary is functionally identical but structurally completely different, making even heuristic-based signature detection extremely challenging. Stealth viruses intercept operating system calls to the file system, presenting the original uninfected file content when security tools request to read an infected file while serving the infected version when the operating system executes it.

Worms represent the self-replicating autonomous branch of malware. Unlike viruses, worms require no host file and no user action to propagate. They exploit vulnerabilities in network services, email systems, or shared resources to copy themselves from system to system without any human involvement. Because most computing infrastructure is networked, worms can spread at network speed — far faster than any human-mediated infection vector.

Worm propagation mechanisms vary by design and target. Network service exploitation worms target specific vulnerabilities in services exposed across the network: the Conficker worm exploited a Windows Server Service vulnerability tracked as MS08-067 to infect Windows systems across local networks and the internet. The WannaCry worm exploited the NSA-developed EternalBlue exploit for a Windows SMB vulnerability tracked as MS17-010, for which Microsoft had released a patch two months before the attack began — systems that had not applied the patch remained vulnerable. Email self-replication worms query the infected system's address book and send copies of themselves to every contact, generating enormous email volume. P2P network worms spread through peer-to-peer file sharing networks by disguising themselves as popular content. Removable media worms exploited Windows autorun functionality to execute automatically when infected media was inserted, which Conficker also leveraged in addition to its network exploitation vector.

The history of worms provides essential context for understanding why patch management and network segmentation are treated as foundational security controls. The Morris Worm of 1988 was the first significant worm to propagate across the internet, exploiting vulnerabilities in the fingerd daemon, sendmail, and the rsh service on Unix systems. Its creator, Robert Morris, was the first person convicted under the Computer Fraud and Abuse Act. The incident effectively coined the term worm in computer security and prompted the creation of the first Computer Emergency Response Team at Carnegie Mellon University. The ILOVEYOU worm of 2000, originating in the Philippines, spread via email and IRC file transfers and overwrote numerous file types with copies of itself, causing approximately ten billion dollars in estimated damage and infecting approximately ten percent of all internet-connected computers within days. Code Red in 2001 exploited an IIS web server vulnerability to deface websites and launch a distributed denial-of-service attack against the White House's IP address. The Slammer worm of 2003 targeted a vulnerability in Microsoft SQL Server and propagated with astonishing speed, doubling in size every 8.5 seconds and infecting most vulnerable hosts on the internet within approximately ten minutes of launch — the fastest-spreading worm ever observed.

Conficker, appearing in 2008, exploited the MS08-067 Windows vulnerability and infected between nine and fifteen million computers, creating a massive botnet whose operators never definitively weaponized it — it remains one of the most successful worm deployments in terms of scale. Stuxnet, discovered in 2010 and attributed to a joint US-Israeli intelligence operation, was the first known cyber weapon designed to cause physical damage to industrial equipment. It targeted Iranian uranium enrichment centrifuges, using four separate zero-day vulnerabilities to propagate and install itself on Siemens programmable logic controller systems, where it subtly modified centrifuge operating parameters to cause mechanical failure while reporting normal operation to monitoring systems. Stuxnet demonstrated that worms could be precision weapons targeted at specific hardware configurations rather than opportunistic broad-spectrum infections. WannaCry in May 2017 combined the EternalBlue SMB exploit with ransomware functionality, infecting over 200,000 systems across 150 countries within days and crippling the UK National Health Service, disrupting patient care and surgical schedules across hundreds of hospitals. NotPetya, appearing the following month, used the same EternalBlue exploit combined with the Mimikatz credential extraction tool for additional propagation and delivered a wiper payload disguised as ransomware — the decryption mechanism was deliberately non-functional, making recovery impossible. NotPetya is attributed to the Russian GRU and caused approximately ten billion dollars in damage to global shipping, pharmaceutical, and logistics companies.

Defenses against viruses center on antivirus and anti-malware with regularly updated signatures, behavioral and heuristic detection engines capable of catching polymorphic and metamorphic variants, the disabling of Office macro execution for documents from untrusted sources, aggressive email filtering that blocks executable attachments and analyzes document macros in sandboxes, and application allowlisting that prevents unauthorized executables from running. Defenses against worms center fundamentally on patch management — the WannaCry and NotPetya outbreaks were entirely preventable for organizations that had applied a patch released two months earlier. Network segmentation limits the lateral movement of worms that do gain a foothold, preventing a single infected endpoint from reaching every other system in the environment. Host-based firewalls and perimeter network firewalls restrict inbound connections on the ports that network-exploiting worms target. Disabling unnecessary network services eliminates the exposure that many worm propagation mechanisms require. Intrusion detection and prevention systems with worm propagation signatures can identify and block worm traffic on the network before it reaches vulnerable hosts.

For the Security+ exam, candidates should be able to define viruses and worms, distinguish them by propagation mechanism, identify the major virus subtypes including file-infecting, macro, boot sector, polymorphic, and metamorphic, recognize the significant worm incidents including WannaCry, NotPetya, Conficker, and Stuxnet, and identify patch management and network segmentation as the primary worm defenses.
