Security professionals use a wide range of specialized tools across different domains of security operations, testing, monitoring, and forensics. The Security+ exam tests knowledge of which tools are used for which purposes, what their key capabilities are, and how they fit into larger security workflows. Understanding the purpose, function, and appropriate use case for each category of security tool is essential for both the exam and for practical security work.

Network intrusion detection and prevention systems monitor network traffic for signatures of known attacks and behavioral anomalies. Snort is the most widely deployed open-source network intrusion detection system. Developed by Sourcefire and now maintained by Cisco, Snort operates in three modes: sniffer mode displays packets as they traverse the network, packet logger mode records packets to disk for later analysis, and NIDS mode matches traffic against a database of attack signatures and generates alerts when matches are found. Snort rules specify the characteristics of traffic to match including protocol, source and destination addresses and ports, and content patterns within the packet payload. Suricata is a high-performance, multi-threaded alternative to Snort that supports the same rule format and adds native inline IPS capabilities, network security monitoring functions, and better performance on high-throughput networks. Zeek, formerly known as Bro, takes a fundamentally different approach from signature-based IDS systems — instead of matching traffic against attack signatures, Zeek extracts metadata and generates structured logs describing network activity: DNS queries and responses, HTTP requests and responses, TLS certificate information, and connection records. Zeek logs are extremely valuable for security investigation and threat hunting because they provide a rich, queryable record of what happened on the network without requiring the storage and processing overhead of full packet capture. OSSEC is a host-based intrusion detection system that analyzes operating system logs, monitors file integrity, and detects rootkits on individual hosts. Wazuh is a fork of OSSEC that has evolved into a comprehensive open-source security platform combining HIDS, log analysis, vulnerability detection, and compliance checking in a single platform with a modern web interface, making it a viable free alternative to commercial SIEM products for small and medium organizations.

Vulnerability scanners identify weaknesses in systems and applications that could be exploited by attackers. Tenable Nessus is the most widely used vulnerability scanner in the industry, maintaining the most extensive plugin database and supporting authenticated scanning across Windows, Linux, network devices, and cloud systems. Nessus supports SCAP compliance assessment against CIS Benchmarks and DISA STIGs and integrates with enterprise management platforms. Qualys VMDR is a cloud-based vulnerability management platform that combines agent-based endpoint scanning, network scanning, and Cloud Security Posture Management in a unified platform. Rapid7 InsightVM provides vulnerability management with exploit awareness informed by Metasploit, providing context about which vulnerabilities have functional exploits available. OpenVAS, distributed by Greenbone Networks, is the leading open-source vulnerability scanner capable of performing comprehensive authenticated network scanning without license cost. Nmap with Nmap Scripting Engine scripts extends basic port scanning to include service version detection and vulnerability checking through a library of community-developed scripts.

Network analysis tools provide visibility into network traffic at multiple levels of detail. Wireshark is the standard graphical packet capture and protocol analysis tool, providing display filters that isolate traffic of interest, protocol dissectors that decode hundreds of application protocols, and analysis features including stream following, object extraction from HTTP sessions, and TLS decryption using session keys. Wireshark captures are saved in pcap format that can be shared for collaborative analysis or processed by automated tools. Tcpdump is the command-line equivalent, essential for capturing traffic on Linux servers and network appliances where graphical tools are unavailable — a command such as tcpdump -i eth0 -w capture.pcap captures all traffic on the eth0 interface and writes it to a file for later analysis in Wireshark. Nmap performs network discovery and security scanning: a basic TCP connect scan enumerates open ports, service version detection with the -sV flag identifies the software behind each open port, OS fingerprinting with the -O flag infers the target's operating system from network behavior, and UDP scanning with the -sU flag discovers UDP services that TCP scans miss. Netcat, often called the network Swiss army knife, provides raw TCP and UDP connectivity for port scanning, file transfer, and establishing reverse shell connections. NetFlow collectors aggregate traffic flow metadata from NetFlow-capable network devices to provide traffic pattern analysis and capacity planning information that also serves as a security monitoring resource.

Password and credential tools are used in authorized penetration tests and forensic investigations. Hashcat is a GPU-accelerated password hash cracking tool that uses the massive parallelism of modern graphics processors to test billions of password candidates per second against captured password hashes. Hashcat supports multiple attack modes: dictionary attacks test every word in a wordlist, rules-based attacks apply transformation rules to wordlist entries to generate variations, brute force attacks systematically test all possible character combinations, and hybrid attacks combine wordlists with brute force character appending. Hashcat supports all major hash types including NTLM, Kerberos, MD5, SHA-1, SHA-256, bcrypt, and over 300 others. John the Ripper is a CPU-based password cracking tool notable for automatic hash type detection and cross-platform support. Hydra performs online password attacks against network services by sending authentication attempts over the network — it supports SSH, FTP, HTTP, HTTPS, SMB, LDAP, and many other protocols, making it useful for testing whether network services allow weak credentials. Mimikatz is the most widely used Windows post-exploitation credential extraction tool, capable of extracting NTLM password hashes and in some configurations plaintext passwords from the LSASS process memory, enabling pass-the-hash attacks that allow authentication using captured hashes without knowing the plaintext password, and pass-the-ticket attacks using captured Kerberos tickets. Mimikatz also implements the Golden Ticket attack against Active Directory Kerberos, which forges Kerberos tickets when the KRBTGT account hash is known. Mimikatz requires administrative or SYSTEM-level access on the target and is both a legitimate penetration testing tool and the most common credential harvesting tool used by attackers.

Web application security tools focus specifically on testing the security of web applications and APIs. Burp Suite is the industry-standard web application penetration testing platform, providing an intercepting proxy that captures and allows modification of HTTP and HTTPS requests between the browser and the server, a scanner that automatically tests for common web vulnerabilities including SQL injection and XSS, a repeater that allows manual crafting and resending of modified requests, and an intruder module that automates attack payloads for fuzzing and brute force. OWASP ZAP is a free alternative to Burp Suite that provides intercepting proxy and automated scanning capabilities suitable for development teams integrating security testing into CI/CD pipelines. Nikto is a web server scanner that checks for common issues including outdated server software, default files and directories, security-relevant HTTP headers, and publicly known vulnerabilities in web server software. Sqlmap automates the detection and exploitation of SQL injection vulnerabilities, automatically detecting injection points, identifying the database type, and extracting database contents.

Exploitation frameworks provide organized collections of exploit code and post-exploitation tools for authorized penetration testing. Metasploit Framework is the most comprehensive open-source exploitation platform, providing exploit modules for hundreds of known vulnerabilities, payload generation for establishing remote control, auxiliary modules for scanning and enumeration, and post-exploitation modules for privilege escalation and lateral movement. Metasploit's Meterpreter payload provides an advanced interactive shell with built-in capabilities for file system access, registry manipulation, credential extraction, pivoting through compromised hosts, and screenshot capture. Cobalt Strike is a commercial adversary simulation platform widely used by red teams for its advanced command-and-control capabilities, team collaboration features, and malleable C2 profiles that allow the attacker's traffic to mimic legitimate application protocols to evade detection. Cobalt Strike is also extensively used by real threat actors, and detecting Cobalt Strike beacons is a common challenge in incident response.

Digital forensics tools enable the collection, preservation, and analysis of digital evidence from compromised systems. Autopsy with The Sleuth Kit provides an open-source graphical platform for disk image analysis including file system examination, deleted file recovery, timeline analysis, keyword searching, and hash-based identification of known files. FTK, the Forensic Toolkit from AccessData, is a commercial forensic platform commonly accepted in legal proceedings. Volatility is the primary open-source memory forensics framework, capable of extracting process lists, network connections, registry hives, and loaded modules from memory dumps acquired from Windows, Linux, and macOS systems — memory forensics is essential for investigating fileless malware and rootkits that leave minimal disk artifacts. EnCase is a comprehensive commercial digital forensics platform widely used by law enforcement and corporate investigations. For forensic image acquisition, the dd command on Linux creates exact bit-for-bit copies of storage devices, and dcfldd adds MD5 and SHA-1 hash computation during imaging to verify integrity. FTK Imager provides a graphical interface for Windows-based forensic image acquisition with integrated MD5 and SHA-256 verification.

Endpoint Detection and Response platforms combine continuous behavioral monitoring of endpoints with rapid investigation and response capabilities. CrowdStrike Falcon uses cloud-based AI to detect malicious behavior based on behavioral patterns rather than only known malware signatures, providing real-time visibility into process execution, network connections, file operations, and registry modifications. Microsoft Defender for Endpoint provides EDR capabilities integrated with the Windows platform. Carbon Black by VMware provides behavioral threat detection with application control capabilities. SentinelOne uses autonomous AI-driven detection and response. Cortex XDR by Palo Alto Networks extends detection across endpoints, network, and cloud.

The Security Content Automation Protocol, abbreviated SCAP, is a standardized framework maintained by NIST that enables automated security compliance checking across diverse security tools. SCAP defines a common language for describing vulnerabilities, configuration issues, and security baselines so that different tools — vulnerability scanners, configuration management tools, and compliance platforms — can consistently identify and report the same issues. SCAP-compliant tools can automatically check systems against DISA STIGs and CIS Benchmarks and produce standardized compliance reports, enabling automated verification that security baselines are maintained across large environments without requiring manual configuration inspection.

SIEM platforms provide the centralized log management, correlation, and alerting capabilities described in the security monitoring context. Splunk is the market leader, providing a powerful proprietary query language called SPL that enables complex analysis of machine data across virtually any log format. Microsoft Sentinel is a cloud-native SIEM and SOAR platform with tight integration with Azure services and Microsoft 365. IBM QRadar provides integrated SIEM and network activity monitoring with extensive integration with enterprise security tools. Elastic SIEM is an open-source alternative built on the Elastic Stack that provides scalable log storage and analysis with flexible deployment options.

Reconnaissance and OSINT tools support the information-gathering phase of security assessments. Maltego provides graphical visualization of relationships between entities such as domains, IP addresses, email addresses, and organizations gathered from open-source intelligence sources, enabling analysts to map attacker infrastructure. Recon-ng is a modular reconnaissance framework for automating OSINT gathering from web services and databases. TheHarvester gathers email addresses, domain names, subdomains, and employee names from public sources including search engines, LinkedIn, and certificate transparency logs. Shodan is a search engine for internet-connected devices that indexes service banners from all publicly accessible hosts, enabling discovery of internet-exposed services, default credentials, and misconfigured systems by searching for specific software versions, device types, or geographic locations.
