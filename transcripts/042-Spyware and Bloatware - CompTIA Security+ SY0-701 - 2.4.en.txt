Spyware and bloatware occupy a broad and sometimes overlapping region of the malware and unwanted software landscape. Spyware ranges from sophisticated criminal credential-theft tools to commercial monitoring software with debatable consent, while bloatware ranges from merely inconvenient pre-installed applications to software with genuine security implications. Both categories are covered on the Security+ exam and both require understanding not just what the software does but how it is installed, detected, and removed.

Spyware is software that covertly monitors user activity and collects information without meaningful informed consent. The defining characteristic is stealth — the user is unaware of the monitoring or has agreed to it under conditions that obscure its true scope. Spyware installation vectors mirror those of other malware: it arrives through peer-to-peer file sharing networks, bundled with free software downloads, through fake security software that presents itself as a protection tool while actually installing the threat, and through malicious links in email. Once installed, spyware embeds deeply in the operating system and often employs techniques to resist removal.

Keyloggers are the most consequential spyware subtype because they capture authentication credentials in transit. Every username and password typed into a keyboard passes through the keylogger before it reaches the application, defeating encryption that protects data in storage and in transit. Hardware keyloggers are small physical devices inserted between the keyboard and the computer, or embedded within keyboards themselves. They record keystrokes to internal flash memory or transmit wirelessly, and they are completely invisible to software security tools because they operate below the operating system. Hardware keyloggers have been found installed on hotel business center computers, library terminals, and ATM keyboards, where they silently accumulate credentials from dozens or hundreds of victims over days or weeks. Software keyloggers hook into the operating system's keyboard input API — on Windows through SetWindowsHookEx for low-level keyboard hooks or GetAsyncKeyState for polling — and run as background processes, often with rootkit-like techniques to hide from process listings. Commercial remote administration tools sometimes include keylogging as a legitimate feature for employer monitoring, but criminal keyloggers specifically target banking credentials, email passwords, credit card numbers, and any other authentication material typed on the system. The captured keystrokes are accumulated in a local file and transmitted to attacker-controlled servers periodically. Password managers partially mitigate keylogger risk: because they autofill credentials without keyboard typing, a keylogger captures nothing useful for autofilled fields.

Screen capture spyware periodically takes screenshots or records continuous screen video, particularly triggering captures when banking websites, payment processors, or cryptocurrency exchanges are detected in the foreground. This supplements keystroke capture with visual context, capturing information that might not pass through the keyboard such as data displayed on screen but not typed. Browser spyware intercepts web activity more comprehensively: it can capture form submissions including fields marked as password fields before they are submitted to the server, modify search results to redirect users to attacker-controlled sites, inject advertisements into viewed pages, and track browsing history for transmission to data brokers or analysis by attackers. Browser-based credential theft often targets the stored passwords in the browser's password manager rather than requiring the user to type them. Credential harvesting spyware specifically targets authentication for high-value applications — banking apps, email clients, cryptocurrency wallets — monitoring for those application windows and capturing credentials through a combination of keylogging, screen capture, and memory scraping.

Adware is software that displays unwanted advertising, typically bundled with free software as a monetization mechanism. The user accepts a lengthy terms of service agreement that technically discloses the advertising, but the disclosure is buried in legal language that no typical user reads. Adware may change browser homepage and default search engine settings without prominent notification, inject additional advertisements into web pages the user is legitimately visiting, create unwanted desktop shortcuts, and install browser toolbars or extensions. Adware and spyware frequently arrive together — the adware provides revenue while the bundled spyware collects and sells data. The security industry uses the term Potentially Unwanted Program or Potentially Unwanted Application to describe software that may not be overtly malicious but whose behavior falls outside what a reasonable user would consent to if fully informed.

Browser hijacking is a specific adware behavior in which the browser's homepage, default search engine, and new tab page are changed to attacker-controlled or monetized alternatives without clear authorization. Browser hijacking software may also install browser extensions that persist even if the homepage settings are manually restored, and may redirect users to proxied versions of legitimate sites that inject advertisements or phishing content. Some browser hijackers redirect specific searches — particularly searches for competing antivirus or security products — to pages promoting the attacker's preferred alternatives.

Tracking technologies span a spectrum from legitimate analytics to privacy invasion. Persistent cookies are the standard web tracking mechanism, storing a unique identifier that the website uses to recognize the user across visits. Supercookies, also called evercookies, use multiple browser storage mechanisms — standard cookies, local storage, IndexedDB, cached content, and others — so that even if the user deletes cookies, the tracking identifier is reconstructed from other storage locations. Browser fingerprinting identifies users without cookies by collecting a unique combination of browser version, installed fonts, screen resolution, timezone, language settings, and installed plugins that together form a fingerprint statistically unique to that browser instance. Tracking pixels embedded in email messages are small transparent images loaded from the sender's server when the email is opened, confirming that the email address is active and the message was opened, including the time and location of opening.

Stalkerware is commercial spyware marketed primarily for monitoring intimate partners, spouses, or children without their knowledge. It typically hides itself from the device's application list, transmits location data, messages, call records, and media continuously to a remote server accessible to the purchaser, and survives factory reset in some implementations. Stalkerware has been increasingly recognized by domestic violence advocates and technology policy organizations as an enabler of intimate partner abuse, and both Apple and Google have policies prohibiting the promotion of applications for non-consensual monitoring, though enforcement remains imperfect. Security researchers and antivirus vendors have established a coalition specifically focused on stalkerware detection and victim notification.

Data harvesting at scale is the commercial model underlying much of the spyware ecosystem. Mobile applications, free services, and spyware-infected systems collectively feed data to brokers who compile comprehensive profiles including location history, app usage patterns, browsing habits, purchasing behavior, and demographic inferences. These profiles are sold to advertising networks, background check services, law enforcement agencies, and anyone else willing to pay, creating a surveillance economy whose full scope most users are unaware of.

Bloatware, sometimes called crapware, refers to pre-installed manufacturer software on new devices. Hardware manufacturers collect payments from software vendors to include their applications on devices at the point of sale, passing the cost back to the end user in the form of unwanted applications consuming storage space, running at startup, and introducing potential security vulnerabilities on a device that has never been used. Lenovo's Superfish incident in 2015 illustrated the security consequences most dramatically: Lenovo pre-installed advertising software that installed its own root certificate authority in the Windows trusted certificate store and used it to conduct SSL man-in-the-middle interception, injecting advertisements into HTTPS-encrypted web pages. Because Superfish's root certificate was installed on all affected laptops with the same private key — a key that was eventually extracted and published — any attacker could generate fraudulent certificates trusted by affected devices, making every HTTPS connection vulnerable to eavesdropping and impersonation from anyone on the network.

Removing bloatware is conceptually simple but practically can be difficult. Some bloatware appears in the installed applications list and can be removed through the standard uninstall process. Some requires running a vendor-provided uninstaller from the application directory or Start Menu. Some has no straightforward removal path, requiring third-party uninstallation tools or a clean OS reinstallation to eliminate completely.

Defenses against spyware combine multiple approaches. Integrated antivirus and anti-malware with spyware detection capabilities scans running processes and loaded modules. Dedicated anti-malware tools such as Malwarebytes specialize in detecting and removing adware and spyware that general-purpose antivirus may miss. Regular audits of installed applications and browser extensions identify unexpected additions. Network traffic monitoring can detect spyware calling home to collection servers. Mobile application permission auditing — reviewing which applications have been granted access to the microphone, camera, contacts, and location — surfaces applications with excessive permissions. The Anti-Malware Scan Interface on Windows provides a standard mechanism for security products to scan scripts before they execute, addressing script-based spyware delivery. Hardware port locks physically prevent hardware keylogger installation on shared or public-facing computers. Physical inspection of keyboards, ATM card readers, and shared computer keyboards can detect hardware keyloggers before they accumulate significant captured data.

For the Security+ exam, candidates should distinguish hardware keyloggers from software keyloggers, understand why adware and spyware frequently arrive bundled together, know what distinguishes stalkerware from generic monitoring software, and recognize the Superfish incident as an example of bloatware creating genuine cryptographic security risk.
