Endpoint security addresses the protection of individual computing devices — workstations, laptops, servers, mobile devices — that connect to an organization's network and access organizational data. Endpoints are among the most targeted assets in modern attacks because they are operated by humans who can be deceived through social engineering, they run complex software that contains exploitable vulnerabilities, and they often leave the protection of the organizational network perimeter to connect from home networks, coffee shops, hotels, and other untrusted environments. Perimeter-focused security alone is insufficient in this context: a firewall protecting the network edge provides no protection to a laptop that is compromised while connected to an airport Wi-Fi network. Endpoint security requires a layered approach that places controls directly on the device, providing protection regardless of network location.

Antivirus and anti-malware software represents the most established layer of endpoint security. Signature-based detection is the traditional approach, where the antivirus engine maintains a database of known malware patterns and scans files and processes for matches. Signature-based detection is fast, accurate for known threats, and has very low false positive rates against known malware families, but it fails entirely against new malware that has not yet been added to the signature database and against polymorphic and metamorphic malware that intentionally mutates its code to avoid signature matching. Heuristic detection addresses this limitation by analyzing the code structure and behavioral characteristics of programs without relying on exact signature matching. By looking for code patterns, obfuscation techniques, and structural features associated with malware families, heuristic engines can detect variants of known malware even when the signature has changed. However, heuristic detection introduces the possibility of false positives, where legitimate programs trigger alerts. Behavioral detection operates at runtime, monitoring the actual behavior of executing processes rather than their code before execution. A behavioral detection engine watches for malicious actions such as privilege escalation attempts, code injection into other processes, creation of network connections on unusual ports, encryption of large numbers of files in rapid succession, and access to credential storage areas. Because behavioral detection responds to what a program does rather than what it looks like, it can detect entirely new malware families and sophisticated threats that evade both signature and heuristic detection.

Endpoint Detection and Response, or EDR, represents the current state of the art in endpoint security and extends far beyond traditional antivirus. EDR agents continuously record all endpoint activity — every process created, every network connection established, every file written or deleted, every registry key modified, every user action — creating a rich telemetry stream that is forwarded to a cloud-based analysis platform. This continuous recording serves two purposes: it enables real-time detection using behavioral analytics and machine learning models, and it creates a historical forensic record that allows investigators to reconstruct exactly what happened on a system during and after a compromise. Threat hunting capability is one of the most powerful features of EDR platforms: analysts can query historical telemetry across the entire fleet of endpoints with hypothesis-driven questions, such as asking which systems executed a specific process or established connections to a specific external IP in a given time window. Automated response capabilities allow security teams to quarantine a compromised host from the network with a single click, kill malicious processes remotely, and in some platforms roll back changes made by ransomware to restore encrypted files to their pre-encryption state. Integration with threat intelligence platforms allows known malicious file hashes, IP addresses, and domain names to be automatically blocked across all endpoints as soon as they are identified. The major EDR vendors include CrowdStrike Falcon, which dominates the market and is widely regarded as having industry-leading detection capability; Microsoft Defender for Endpoint, which benefits from deep integration with the Windows operating system and the Microsoft security ecosystem; SentinelOne, which emphasizes autonomous AI-based response; Carbon Black from VMware; and Cortex XDR from Palo Alto Networks.

Extended Detection and Response, or XDR, extends the EDR concept beyond individual endpoints to correlate security telemetry across multiple security domains simultaneously. An XDR platform ingests data from endpoints via the EDR agent, from network monitoring sensors, from cloud workload security agents, and from email security systems, then applies cross-domain correlation to detect threats that would be invisible when looking at any one domain in isolation. An attacker who compromises an email account, uses it to send a malicious link to internal targets, establishes command-and-control from a compromised endpoint, and begins lateral movement across the network generates signals across all four domains. XDR correlates these signals into a unified incident view, dramatically reducing the investigation time that would otherwise be required to manually correlate separate alerts from separate tools.

Host-based Intrusion Detection and Prevention Systems, or HIDS and HIPS, provide monitoring and protection at the individual system level. OSSEC and its modernized fork Wazuh are the most widely deployed open-source HIDS platforms. They provide file integrity monitoring that detects changes to critical system files, log analysis that identifies suspicious patterns in local system logs, rootkit detection that looks for signs of hidden processes and files, and active response capabilities that can automatically block IP addresses or take other protective action when a threat is detected. OSSEC and Wazuh also support centralized management where agents on multiple endpoints forward data to a central manager for aggregated analysis and correlation.

Host-based firewalls provide network access control directly on the endpoint. Windows Defender Firewall with Advanced Security, configurable through Group Policy in enterprise environments, filters both inbound and outbound network connections based on port, protocol, remote address, and application. Windows Defender Firewall supports multiple profiles — domain, private, and public — applying different rule sets depending on whether the system is connected to a domain network, a trusted private network, or an untrusted public network. This allows appropriate restrictions to be applied when a laptop connects to an untrusted public network without interfering with normal operations on the domain network. Linux hosts use iptables, its modernized replacement nftables, or the user-friendly firewalld front-end to manage host-based firewall rules.

Endpoint DLP agents monitor file operations on workstations, watching for sensitive data being written to removable USB storage, attached to outgoing email, uploaded to cloud storage services, or printed. When a DLP policy is triggered by the detection of sensitive data patterns such as credit card numbers, social security numbers, or classified document keywords, the agent can block the operation, generate an alert, or both. Endpoint DLP complements network DLP by protecting against data exfiltration that bypasses the network, such as copying files to a locally connected USB drive or burning data to optical media.

Application control restricts which executables and scripts can run on an endpoint. Windows Defender Application Control, or WDAC, operates at the kernel level, enforcing code integrity policies that prevent unauthorized code from loading entirely. WDAC is the more secure option because it cannot be bypassed from user mode. AppLocker is a Group Policy-based application restriction mechanism that operates in user mode, defining rules based on file path, cryptographic hash, or digital signature publisher. AppLocker is easier to deploy than WDAC and is appropriate for most enterprise environments, with WDAC reserved for the highest-security scenarios.

Disk encryption on endpoints protects against the physical theft threat where an attacker obtains a device and attempts to read data from the storage directly, bypassing OS access controls. BitLocker with TPM-backed pre-boot authentication on Windows ensures that the disk cannot be read if the storage is removed from the system or if the system is booted from external media. Recovery keys stored in Active Directory or Azure Active Directory allow administrators to recover access if needed. BitLocker should be mandatory on all portable systems because laptops are routinely lost or stolen, and unencrypted laptops frequently result in data breach notification obligations.

Patch management for endpoints ensures that vulnerabilities in the OS and applications are remediated promptly. WSUS provides centralized Windows update management in enterprise environments. Third-party patch management solutions such as Ivanti, ManageEngine Patch Manager Plus, and PDQ Deploy extend patch management to non-Microsoft software, which represents a large and frequently exploited portion of the attack surface. A mature patch management process includes testing patches in a non-production environment before broad deployment, deploying by ring or wave to limit impact if a patch causes problems, and tracking compliance to ensure all systems reach the patched state.

Mobile endpoint management uses Mobile Device Management, or MDM, platforms including Microsoft Intune, Jamf for macOS and iOS, and VMware AirWatch for Android. These platforms enforce security policies such as requiring screen lock PINs or biometrics, enforcing disk encryption, requiring OS updates, preventing installation of applications from unapproved sources, and enabling remote wipe if a device is reported lost or stolen. Compliance checking allows MDM platforms to verify that a device meets security requirements before granting access to corporate resources, integrating with conditional access policies in identity platforms.

Posture assessment is the process of evaluating the security state of an endpoint before or during network access. A network access control solution checks whether the connecting device meets security requirements — is antivirus installed and current? Are OS patches applied? Is disk encryption enabled? — and places non-compliant devices in a quarantine network with restricted access until they can be brought into compliance. This prevents devices with outdated software or missing security controls from connecting to the production network and potentially spreading malware or creating vulnerabilities.
