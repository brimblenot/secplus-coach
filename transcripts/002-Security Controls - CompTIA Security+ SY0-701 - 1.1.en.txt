Security controls are the mechanisms, policies, procedures, and safeguards that organizations use to protect their systems, data, people, and physical assets. The CompTIA Security+ exam requires you to understand both the categories of security controls and the types of security controls, and to be able to map any given control to its appropriate category and type. This framework forms the foundation of everything else in security because it gives professionals a systematic way to design layered defenses, commonly called defense-in-depth.

There are four broad categories of security controls. The first is the technical category, sometimes called logical controls. Technical controls use technology to enforce security policy. Examples include firewalls that filter network traffic based on rules, antivirus and antimalware software that detects and blocks malicious code, operating system security policies that control which users can access which resources, encryption that protects data at rest and in transit, and intrusion detection or prevention systems. A Security Information and Event Management system, known as a SIEM, is also a technical control because it aggregates logs from across the environment and uses technology to correlate events and alert analysts to potential incidents.

The second category is managerial controls, sometimes called administrative controls. Managerial controls are implemented through documentation, policies, and procedures rather than through technology or people directly. Examples include an organization's overall security policy document, onboarding policies that define what access new employees receive and what security training they must complete, security procedures and standard operating procedures, risk assessments, and security program governance documentation. Managerial controls set the rules that all other controls are designed to enforce.

The third category is operational controls. Operational controls rely on people to implement and carry out security processes. If humans are directly performing the security function, it is an operational control. Examples include security guards stationed at checkpoints, monthly security awareness lunch-and-learn sessions that educate employees about phishing and social engineering, awareness poster campaigns, property patrols by security personnel, and incident response teams. These controls depend on human judgment and consistent execution.

The fourth category is physical controls. Physical controls limit physical access to buildings, rooms, systems, and devices. Examples include perimeter fencing, door locks, badge readers and access card systems, guard shacks at facility entrances, bollards that prevent vehicle ramming attacks, and security lighting. Physical controls are often the first layer encountered by anyone attempting unauthorized access to an organization's facilities.

Within these four categories, security controls are also classified by six functional types that describe what the control actually does. Understanding both the category and the type for a given control is essential for the exam and for real-world security program design.

The first type is a preventive control. Preventive controls attempt to stop a security incident from occurring in the first place. They block or restrict access before any harm can be done. In the technical category, a firewall rule that blocks traffic from unauthorized IP addresses is a preventive technical control. In the managerial category, an onboarding security policy that requires background checks before granting system access is a preventive managerial control. In the operational category, a security guard checking identification before allowing entry is a preventive operational control. In the physical category, a door lock preventing entry to a server room is a preventive physical control.

The second type is a deterrent control. Deterrent controls do not necessarily prevent access but create an environment that discourages attackers from even attempting an attack. They raise the perceived cost or risk of the attack. In the technical category, a login warning banner that informs users their activity is monitored serves as a deterrent by making potential attackers aware of the consequences of unauthorized access. In the managerial category, a policy that clearly states employees may face demotion or termination for accessing systems outside their authorization serves as a deterrent. In the operational category, a staffed reception desk that greets and verifies every visitor creates a deterrent effect. In the physical category, prominently displayed warning signs indicating that an area is monitored by security cameras and that trespassers will be prosecuted serve as physical deterrents.

The third type is a detective control. Detective controls identify and log security events after they occur, or detect them in real time. They may not prevent an incident but they ensure that incidents are discovered so that a response can be initiated. In the technical category, system logs and a SIEM that reviews and correlates those logs are detective technical controls because they record and surface evidence of unauthorized activity. In the managerial category, a policy requiring managers to review login reports and access logs on a weekly basis is a detective managerial control. In the operational category, security personnel patrolling the property looking for signs of intrusion, vandalism, or unauthorized presence are performing a detective operational function. In the physical category, motion detectors that trigger alarms when movement is detected in areas that should be unoccupied are detective physical controls.

The fourth type is a corrective control. Corrective controls are applied after a security event has been detected. Their purpose is to reverse the damage, restore normal operations, or limit further harm. In the technical category, restoring a system from a clean backup after it has been infected with ransomware is a corrective technical control. In the managerial category, an incident reporting policy that requires employees to escalate security issues so that management can coordinate a response is a corrective managerial control. In the operational category, contacting law enforcement in response to a physical security breach such as a fence breach or unauthorized building entry is a corrective operational action. In the physical category, a fire extinguisher used to suppress a fire and prevent it from spreading is a corrective physical control.

The fifth type is a compensating control. Compensating controls are used when the primary control that would normally address a risk cannot be implemented, often due to cost, time, technical limitations, or business constraints. A compensating control provides an alternative means of reducing risk on a temporary or permanent basis. In the technical category, if a software vendor has announced a critical vulnerability in an application but the patch will not be available for several weeks, an administrator might implement a firewall rule that blocks the specific type of traffic that would exploit that vulnerability. This compensating technical control reduces the risk while waiting for the patch. In the managerial category, implementing separation of duties across multiple individuals so that no single person can complete a sensitive transaction alone is a compensating managerial control. In the operational category, deploying multiple security guards simultaneously so that no single guard has unchecked access to all areas compensates for the risk that a single guard poses. In the physical category, deploying a backup power generator compensates for the risk of a power outage by ensuring systems remain operational while waiting for grid power to be restored.

The sixth type is a directive control. Directive controls are the weakest of the six types because they rely on directing or instructing people to behave securely rather than technically enforcing a behavior. They communicate what is required but depend on voluntary compliance. In the technical category, a file storage policy that directs employees to save sensitive documents only to encrypted folders is a directive technical control. In the managerial category, compliance policies and procedures that document the required security behaviors across the organization are directive managerial controls. In the operational category, security awareness training that instructs employees on how to recognize phishing emails, handle sensitive data, and report suspicious activity is a directive operational control. In the physical category, a sign on a door that reads "Authorized Personnel Only" is a directive physical control. The sign gives direction but does not mechanically enforce it the way a key card lock would.

These four categories and six types form a four-by-six matrix with twenty-four possible combinations. For the exam it is important to be able to place a control anywhere in that matrix and to recognize that a single control can sometimes fit into multiple categories or types simultaneously. For example, a CCTV camera system is both a detective control and a deterrent control, and it is a technical control that also has physical components. The examples used throughout this topic are illustrations, not the only correct answers. Many other examples fit equally well.

As technology evolves, new types of controls may emerge that do not fit neatly into these six types. The framework is designed to be flexible. Organizations should use it as a guide for systematically building a layered security posture, not as a rigid checklist. The goal of combining controls from all four categories and multiple types is to ensure that if one control fails, others remain in place to detect, correct, or compensate. This layered approach is called defense-in-depth, and it is the fundamental design philosophy underlying modern security architecture.
