A threat vector is the method or pathway an attacker uses to gain access to a system, network, or organization. The term is sometimes used interchangeably with "attack vector," though threat vector has a slightly broader meaning that includes vectors not yet exploited. Attackers continuously research and develop new vectors while also exploiting old ones that remain unpatched or improperly configured. A security professional must understand the full landscape of threat vectors to ensure that defenses are comprehensive rather than focused on only the most obvious avenues.

Message-based threat vectors are among the most common and effective because nearly every person and organization relies on electronic communication. Email is the single most common vector for initial access in cyberattacks. Attackers send phishing messages with malicious links pointing to credential-harvesting pages or sites that download malware, and they also send messages with malicious file attachments that execute code when opened. The phishing email works because recipients habitually trust their inbox and are conditioned to respond to messages about billing problems, account alerts, or delivery notifications. SMS text messaging is used in a variant called smishing, where attackers send text messages with links. Mobile users are more likely to click these links because small smartphone screens make URL inspection difficult and because text messages carry a cultural expectation of immediacy. Instant messaging and corporate collaboration platforms such as Microsoft Teams, Slack, and Discord are increasingly targeted. Attackers who gain a foothold inside a corporate messaging platform can impersonate colleagues, share malicious files, and send links that appear far more trustworthy than external email. Attackers also exploit messaging to deliver invoice scams, cryptocurrency fraud, and social engineering messages designed to build trust before making a malicious request.

Image-based attack vectors exploit the fact that image files are processed by complex parsing code and can carry embedded content. The SVG format — Scalable Vector Graphics — is particularly interesting because an SVG file is actually an XML document that describes the image mathematically and can contain embedded JavaScript. When a browser renders an SVG, it may also execute any JavaScript contained in the XML, making SVG a potential vector for cross-site scripting attacks. Browsers have implemented input validation and restrictions on SVG scripts, but vulnerabilities in image parsing code have historically allowed malicious images to exploit browser or application flaws. Steganography involves hiding data or malicious code within image files in ways that are not visible to casual inspection, allowing attackers to exfiltrate data or conceal malicious payloads inside seemingly benign image files. Polyglot files are a more advanced technique: a file that is simultaneously a valid image and valid executable code, exploiting format parsers that make assumptions about file type.

File-based attack vectors encompass any file format that can carry malicious content. Executable files are the most obvious example, but executable-disguised files and document formats with scripting capabilities are far more commonly used in practice because they are less likely to be blocked outright. Microsoft Office documents support VBA macros — small programs that automate document tasks — and attackers embed macros that execute malicious code when a user enables macro functionality. Modern Office applications warn users before running macros, but social engineering messages claiming the document requires macros for "protected content" or "proper formatting" frequently persuade users to enable them anyway. PDF files can contain embedded JavaScript or exploit vulnerabilities in PDF reader software. ZIP and RAR archives can contain hundreds of files, making it easy to hide a single malicious file among legitimate content. Windows LNK shortcut files can be crafted to execute arbitrary commands when opened, and have been used in sophisticated APT attacks. Browser add-in files and extensions are another avenue: a malicious extension installed in a browser can intercept traffic, harvest credentials, and exfiltrate data while appearing to provide a useful function.

Voice call vectors use telephone technology to attack human targets. Vishing, or voice phishing, involves calling targets and impersonating banks, government agencies, the IRS, technical support departments, or IT helpdesks. The attacker creates urgency — claiming a fraudulent charge on the victim's account, or a warrant for their arrest — to override careful thinking and persuade the victim to provide credit card numbers, Social Security numbers, or remote computer access. Caller ID spoofing via VoIP services allows the attacker to make calls appear to come from any number, lending credibility to the impersonation. Spam over IP, sometimes called SPIT, uses automated VoIP systems to dial millions of numbers with recorded social engineering scripts. War dialing — systematically dialing ranges of phone numbers looking for modem connections or other exploitable phone-connected systems — remains a niche but documented technique.

Removable media represents a vector that can bypass even well-configured network perimeter defenses. An attacker who needs to reach an air-gapped network — one physically isolated from the internet — can scatter USB drives in the organization's parking lot, hoping an employee picks one up and connects it to a workstation. This is called baiting. The USB drive contains malware that executes automatically or waits for a user to interact with the files. A more sophisticated form of USB attack uses HID — Human Interface Device — emulation. Devices like the USB Rubber Ducky appear to the computer's operating system as a keyboard. When plugged in, they type hundreds of pre-programmed keystrokes per second, executing commands far faster than any human could type. Because the operating system trusts keyboard input inherently, this bypasses most software security controls. USB drives are also effective tools for data exfiltration: an insider or physical intruder can copy large volumes of sensitive data to a thumb drive and walk out the door. Organizations should disable USB ports where not needed, implement endpoint controls that block unauthorized USB devices, and train employees never to plug in found storage media.

Vulnerable software is a persistent threat vector because software complexity guarantees the presence of unknown vulnerabilities, and the patch lifecycle means that even discovered vulnerabilities exist in unpatched systems for weeks, months, or years. Attackers use exploit kits — packaged tools that automatically test a target system for known vulnerabilities in browsers, PDF readers, Java runtime environments, and other common software — to find and exploit weaknesses. Web-based applications are particularly interesting from an attacker's perspective because the application code runs on a central server that all users connect to; if an attacker can compromise that server, they can potentially affect every user session without needing to attack individual endpoints.

Unsupported systems are devices or operating systems for which the manufacturer no longer releases security patches. Windows XP reached end-of-life in April 2014, Windows Server 2003 in July 2015, and Windows 7 in January 2020. Despite this, all three remain in use in healthcare environments, industrial control systems, and government networks where upgrading is expensive or technically complex. Vulnerabilities discovered after end-of-life have no vendor remedy, meaning compensating controls — network isolation, application allowlisting, enhanced monitoring — are the only available mitigations. IT departments must maintain complete inventories of all devices on the network, including legacy systems running under desks or in storerooms, because unidentified systems cannot be protected.

Unsecured networks create threat vectors through weak or absent encryption and authentication. Open public Wi-Fi access points provide no encryption, allowing any nearby attacker to intercept traffic using passive sniffing or a man-in-the-middle position. WEP — Wired Equivalent Privacy — is a long-deprecated wireless security protocol with well-known cryptographic weaknesses that allow attackers to recover the encryption key within minutes. Evil twin access points mimic the name and appearance of legitimate networks, tricking devices into connecting to an attacker-controlled network. Organizations should enforce WPA3 where possible, require 802.1X port-based authentication for both wired and wireless network access, and conduct periodic scans for rogue access points. Bluetooth is another wireless vector: it can be used for reconnaissance to identify nearby devices, and implementation flaws in Bluetooth stacks have been exploited to gain unauthorized access.

Open service ports increase attack surface. Every service running on a server must listen on a network port, and every open port is a potential entry point if the service has a vulnerability or misconfiguration. Web servers typically expose ports 80 and 443, which is intentional and necessary, but many servers also expose unnecessary services — print spoolers, legacy file sharing protocols, database management interfaces — that should be restricted or disabled. Shodan is an internet search engine that continuously scans and indexes internet-connected devices and their exposed services, making it trivially easy for attackers to find specific service types, software versions, and even devices with known vulnerabilities. Security teams should use Shodan and similar tools offensively to understand their own external attack surface.

Default credentials are factory-set usernames and passwords built into networking equipment, IoT devices, cameras, printers, and routers by manufacturers for initial setup. Common defaults include admin/admin, admin/password, and many model-specific combinations that are publicly documented on sites such as routerpasswords.com. Attackers can combine Shodan searches with default credential lists to gain administrative access to vast numbers of internet-connected devices with minimal effort. Modern devices increasingly force password changes on first login, but millions of older devices remain configured with factory defaults. All default credentials must be changed before any device is deployed.

Supply chain threat vectors compromise a target organization by first attacking a third party with access to the target's systems. Hardware can be tampered with during manufacturing or in the distribution chain, with malicious components or firmware added before the device reaches the customer. Software can be backdoored through compromised build systems, as in the SolarWinds Orion attack of 2020. Managed service providers — companies hired to monitor and maintain an organization's infrastructure — have access to many client environments simultaneously, making them high-value targets. The 2013 Target data breach began when attackers compromised HVAC contractors that had network access to Target's systems, then pivoted from the HVAC management network to the point-of-sale network. Counterfeit hardware — fake Cisco switches, for example — has been documented as a supply chain threat where equipment that appears legitimate contains hidden vulnerabilities or malicious capabilities.

Social media creates threat vectors through information gathering and social engineering. Attackers mine LinkedIn, Facebook, Instagram, and Twitter to identify employees, understand organizational structure, learn about projects, and gather personal details that make targeted phishing emails convincing. Fake profiles can initiate connections and build relationships with employees before delivering a malicious payload or making a social engineering request. Cloud services introduce threat vectors through misconfiguration — improperly secured storage buckets, overly permissive access policies, and inadequate identity controls. BYOD — Bring Your Own Device — policies allow personal devices with unmanaged security configurations to connect to corporate networks, potentially introducing malware or providing a path for data exfiltration. Human factors remain at the core of many successful attacks: attackers exploit psychological principles such as trust, authority, urgency, and fear to bypass technical controls entirely.
